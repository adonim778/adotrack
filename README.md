# Adotrack

A lightweight, responsive workout, meal/macronutrient, and hydration tracker. No framework or build step required. All data is stored locally in the browser using localStorage; it is not synced between devices.

## GitHub Pages
The included GitHub Actions workflow builds and deploys this static site from the `main` branch. Enable Pages in Settings → Pages and choose GitHub Actions as the source if it is not already selected. The live site will be at `https://adonim778.github.io/adotrack/` after the workflow completes.

## Use
Open `index.html`, or publish the repository with GitHub Pages. Log workouts, record meals and macros, switch between three starter workout plans, and track hydration. Daily nutrition targets and the hydration goal are sample defaults in `index.html`; adjust them for your needs. This is a general tracking tool and not medical advice.
